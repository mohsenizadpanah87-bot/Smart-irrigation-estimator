## 🌿 Smart Irrigation System & Cost Estimator (AI-Powered)

###It was designed to solve the manual labor of calculating material requirements and costs for large-scale irrigation projects.

### 🚀 Key Features

**Dynamic Calculation:** Automatically calculates pipes, valves, and emitters based on area dimensions.

**Live Market Pricing:** Connects to price databases (or Google Sheets) to provide real-time cost estimations.

**AI Integration:** Uses Google Gemini to analyze terrain descriptions and suggest the best irrigation strategy.

**Automated Reporting:** Generates a professional summary sent directly to the client via Email/Telegram.

### 🛠 Tech Stack

**Automation:** n8n

**AI Model:** Google Gemini

**Interfaces:** Telegram Bot API / Google Sheets
